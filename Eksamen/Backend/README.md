# Backend - Spring Boot Application

This is the backend service for the Buss-App Østfold project, built with Spring Boot.

## Technology Stack
- Java 17
- Spring Boot 3.x
- Maven
- Spring Data JPA
- Spring Security
- PostgreSQL (planned)

## Development Setup
```bash
# Install dependencies
mvn clean install

# Run the application
mvn spring-boot:run

# Run tests
mvn test
```
